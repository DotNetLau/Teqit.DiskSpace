# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion focused on the work. Harassment, personal attacks and discrimination are not tolerated.

Unacceptable behaviour can be reported to the maintainers through GitHub, for example by contacting the repository owner ([@DotNetLau](https://github.com/DotNetLau)). Reports are handled confidentially.
